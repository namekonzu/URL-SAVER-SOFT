URLBoxは、Windows向けのシンプルで軽量なURL管理ソフトウェアです。

よく使うWebサイトをフォルダごとに整理し、右クリックでコピー、ダブルクリックでそのサイトに飛ぶことができます。

C言語・Win32 API・SQLiteを使用しています

【主な使い方】
・フォルダの追加
  フォルダ追加ボタンをクリック
・ファイルの追加
  追加したいサイトの名前とそのURLを入力欄に入力後、ファイルを追加したいフォルダを選択し、ファイル追加ボタンをクリックする。
・フォルダ、ファイル名の変更
  変更したいフォルダ、ファイルを選択すると、名前変更欄に変える前の名前が出るので、変更したい名前に書き換えて名前変更ボタンをクリックする。
・フォルダ、ファイルの削除
削除したいフォルダ、ファイルを選択し、削除ボタンをクリックする。

【注意点】
・フォルダ削除は子項目も削除される
・たまに色が反転するが、使用できるので、問題なし
